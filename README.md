# 📈 Zerodha Clone - Stock Trading Platform

A modern and responsive stock trading platform inspired by Zerodha, built using React.js and modern web technologies. This project replicates the core user interface and functionality of a real-world trading application, allowing users to explore stocks, manage portfolios, view market data, and experience a professional trading dashboard.

---

## 🚀 Live Demo

🔗 Live Website: https://zerodha-frontend-cwas.onrender.com/

---

## 📌 Project Overview

The Zerodha Clone is a frontend web application designed to simulate a stock trading platform. It provides users with an intuitive and responsive interface to monitor stock market trends, manage investments, and track portfolio performance.

The project focuses on creating a clean user experience similar to Zerodha's Kite platform while implementing modern frontend development practices.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/zerodha-clone.git
```

### Navigate to Project Folder

```bash
cd zerodha-clone
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Application will run on:

```bash
http://localhost:5173
```

---

## 🏗️ Build for Production

```bash
npm run build
```

Preview Production Build:

```bash
npm run preview
```
